# SeekDesk 专用代理（本机测试功能）

进入 **扩展中心 → SeekDesk 专用代理 → 添加节点 / 订阅**。

- **节点链接 / 批量导入**：粘贴一个或多个分享链接，每行一个；也可粘贴 Base64 列表或 Clash YAML / JSON。
- **订阅链接**：填写 HTTP/HTTPS 订阅地址，点击“获取订阅”，检查识别数量及跳过原因，再确认导入。支持明文节点列表、Base64 节点列表和包含 `proxies` 的 Clash 配置。
- 导入后选择节点，再开启代理。订阅不会自动开启连接；可通过订阅行的刷新按钮手动更新。
- 更新会替换该订阅的旧节点，尽可能保留当前选择。下载或保存失败时保留原节点；更新过程中手动修改的节点不会被迟到结果覆盖。
- 节点较多时可按名称、服务器或协议搜索。删除订阅会一并删除其节点；手动添加的节点和其他订阅保留。
- 链接默认明文显示，节点支持多行粘贴，订阅地址使用紧凑的单行输入框。
- 点击节点右侧的闪电图标，立即检测该节点，成功显示毫秒数，失败显示“未连通”。检测通过节点自身协议访问轻量检测地址，包含 Hysteria2 的 UDP 传输；无需开启代理，也不会切换当前节点。延迟结果按需重新检测，不长期缓存。

| 协议 | 分享链接 | 说明 |
| --- | --- | --- |
| VLESS | `vless://` | TCP、WS、gRPC、HTTPUpgrade、XHTTP；TLS / Reality；符合条件的 Vision |
| VMess | `vmess://` | Base64 JSON v2、alterId=0；常见传输，XHTTP 使用默认 mode |
| Shadowsocks | `ss://` | SIP002、旧版 Base64、常用 AEAD 和 SS2022；不含 SIP003 插件 |
| Trojan | `trojan://` | 常见传输及 TLS 参数 |
| Hysteria2 | `hysteria2://`、`hy2://` | TLS、SNI、鉴权及 Salamander 混淆 |
| SOCKS5 | `socks5://`、`socks://` | 无鉴权或用户名/密码 |
| HTTP / HTTPS | `http://`、`https://` | 无鉴权或用户名/密码；HTTPS 可指定 SNI |

Clash 订阅只导入支持的节点参数，不执行远程规则、脚本或 `proxy-providers`。TUIC、SSR、Hysteria v1、端口跳跃、跳过证书验证及未覆盖的附加参数暂不支持。遇到不支持或格式错误的节点，会显示跳过原因；并非所有 Clash 配置均可完整导入。

订阅内容限制为 UTF-8 文本、单次 2 MB、最多 1000 个节点；本机最多保存 1000 个节点和 30 个订阅。节点凭据和订阅地址保存在本机钥匙串。订阅下载不携带 NodeSeek 登录 Cookie，错误提示不展示订阅令牌或服务器返回内容。

代理开启时，订阅请求也使用当前 SeekDesk 代理；节点不可用时不会自动回退直连。首次导入或修复失效订阅时，可由用户主动关闭代理后再获取。

代理仍只作用于 SeekDesk，不修改系统代理，不建立 TUN，不接管其他应用流量。真实远端节点连通性需由用户自行验证；离线配置检查通过不代表服务端可连接。

闪电检测使用独立的临时 Xray 实例和本机随机监听端口，向 `https://www.gstatic.com/generate_204` 发出无 Cookie 的请求，收到预期响应后记录耗时并关闭实例。最多同时检测 4 个节点；修改或删除节点会取消其旧检测，迟到结果不会覆盖新配置。检测不修改系统网络设置，也不发送 NodeSeek 账号信息。
