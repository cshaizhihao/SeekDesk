## SeekDesk V1.5.0

- 使用 Flutter 与 Liquid Glass 着色器重做桌面界面，统一首页、设置、扩展中心和编辑器的交互。
- 三栏阅读支持单独关闭标签、拖动横向滚动条、恢复最近关闭的标签和记忆阅读位置。
- 新增原色、山岚、海岸等外观主题，支持独立的阅读配色和昼夜模式。
- 「只看楼主」汇总整帖的作者回复。等级徽标按级别配色，管理与社区身份独立显示。
- 发帖时可以选择版块和阅读等级。Markdown 编辑器支持分栏预览、图片拖放和动态表情。
- 扩展中心的应用专用代理支持常见节点与订阅链接，以及节点延迟检测。
- 「设置 → 关于」可以检查并直接安装后续正式版。安装前保存可恢复的本地草稿，完成后重启应用。

## 安装与更新

适用于 Apple Silicon Mac，最低 macOS 14。下载 DMG，将 SeekDesk 拖入「应用程序」。V1.0.0 用户需手动安装一次 V1.5.0，后续可在应用内点击「更新并重启」。

DMG 未进行 Apple Developer ID 签名或公证。首次启动可按 macOS 的「隐私与安全性」提示操作。`.sha256` 可校验 DMG；更新 ZIP 和 `appcast.xml` 供应用内更新使用。

SeekDesk 是独立开发的第三方客户端，与 NodeSeek 官方没有隶属关系。帖子内容、账号权限和社区规则均以 [NodeSeek](https://www.nodeseek.com/) 为准。
