- **deerstack** · 服务器实测、避坑教程和实用工具。[官网](https://deerstack.com/)

## 更新方式

- **V1.5.0 用户**可在「设置 → 关于」点击「检查更新」，然后点击「更新并重启」。
- **首次安装或从 V1.0.0 升级**可下载 DMG，将 SeekDesk 拖到「应用程序」。适用于 Apple Silicon Mac，最低 macOS 14。

DMG 未进行 Apple Developer ID 签名或公证，可用同名的 `.sha256` 文件校验。更新 ZIP 和 `appcast.xml` 供应用内更新使用。
